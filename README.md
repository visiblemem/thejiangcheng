# The Jiang Cheng

First narrative web prototype for Jiang Cheng / 蔣誠.

## Current prototype

- Narrative landing experience
- Editorial visual system
- Ambient interactive canvas layer
- Traditional Chinese / Simplified Chinese / English switching
- Work / Film / Music / Writing / Objects / About sections
- Mobile responsive layout
- Static-only architecture suitable for GitHub Pages

## Preview with GitHub Pages

Repository Settings → Pages → Build and deployment → Deploy from a branch → `main` / root.

The expected Pages URL is:

`https://visiblemem.github.io/thejiangcheng/`
